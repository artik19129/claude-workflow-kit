# Память проекта

Этот файл принадлежит проекту: update и uninstall кита его сохраняют. Храни короткую карту доменов, а не историю всех задач. Общая база доступна через навык workflow-memory.

## Действующие ограничения
Добавляй только проверенные особенности проекта: архитектурные границы, тестовое окружение, команды реальной проверки, общие ресурсы. Секреты и рабочие данные сюда не попадают.

## Домены
Добавляй ссылки на `docs/memory/<domain>.md` по мере появления устойчивых уроков. Файл не нужен, пока нет содержательного знания.

## Формат записи
Условие → наблюдавшаяся ошибка → действие → способ проверки. Укажи источник (задача/коммит/тест), дату проверки, область применимости. Исправленный или устаревший вывод пометь как заменённый. Гипотезы и незавершённые действия остаются в файле задачи.
