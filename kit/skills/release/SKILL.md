---
name: release
description: Подготовить запись о релизе в CHANGELOG проекта и предложить коммит. Вызывать по команде /release.
argument-hint: [версия]
---

Чек-лист для оркестратора.

1. Прочитать правила в шапке `CHANGELOG.md` проекта и следовать именно им (формат версий, дат, разделов).
2. Найти текущую неопубликованную версию и пометить её датой публикации в формате, который уже используется в предыдущих записях файла.
3. Открыть заголовок следующей версии (следующая по счёту, если версия не передана аргументом — использовать переданную).
4. Показать CEO итоговый текст записи в CHANGELOG.
5. Предложить коммит `docs(release): версия X.Y.Z` и, если проект тегирует релизы, команду тега.
6. Ничего не пушить.
