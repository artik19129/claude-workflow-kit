---
name: release
description: Подготовить запись релиза в CHANGELOG проекта AI Workflow Kit и предложить локальный коммит.
---

Вызов: `$release` или `$release <версия>`.

Прочитай правила и существующий формат `CHANGELOG.md`. Найди неопубликованные изменения, проверь их по принятым задачам и git log. Подготовь запись указанной версии; без аргумента следуй принятой в проекте нумерации. Сохрани стиль дат и разделов, открой следующий раздел если так принято в проекте. Если CHANGELOG отсутствует, предложи минимальную запись на основе подтверждённых изменений.

Покажи итог и предложи коммит `docs(release): версия X.Y.Z`. Навык сам по себе не разрешает тег, push, создание удалённого релиза или публикацию пакета.
